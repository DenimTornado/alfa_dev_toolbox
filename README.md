# DEV Toolbox

Статический набор инструментов для фронтенд-разработчика: **URL Builder** собирает ссылки, **Build ENV** — аргументы с переменными для сборок.

## Как добавлять

В **Dictionaries** добавьте нужные значения через **Add entry** или **Bulk add**. Затем выбирайте их в билдерах, добавляйте строки и кастомные параметры. Результат можно скопировать отдельно или через **Copy All**.

## Настройки

В **Settings** доступны тема, экспорт и импорт JSON, полный сброс данных. Вкладку справочника можно очистить отдельно через **Clear tab**.

Данные сохраняются в текущем браузере. Для переноса используйте JSON. Версия приложения указана в футере.
